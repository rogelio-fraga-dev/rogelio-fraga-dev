# 🧠 About Me

I'm a **Full Stack Developer focused on complex, decision-driven systems**, working on applications that require **consistency, traceability, and structured business logic**.

I don’t just build APIs or interfaces — I design systems where:

- Business rules are **explicit and isolated**
- Decisions are **traceable and reproducible**
- Frontend and backend share the same **domain language**

Currently working in a **research and innovation environment**, building full-stack systems with real-world complexity.

---

# 🏭 What I Build

- 📊 Systems that process multiple variables into consistent outputs  
- 🔍 Validation layers before executing critical rules  
- 🔄 Transformation of complex inputs into structured decisions  
- 🧠 Design Pattern-driven logic (Strategy, Factory)  
- ⚙️ Fully traceable and auditable systems  

---

# 🏗️ Architecture Mindset

- Clean Architecture applied in real-world scenarios  
- Strong separation of **domain / application / infrastructure**  
- Backend driven by **business rules**  
- Frontend driven by **decision flows**  
- Low coupling, high predictability
